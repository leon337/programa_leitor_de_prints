# Procedimentos do Projeto

## SKILL-001 — Iniciar uma etapa

1. Consultar `docs/CONSTITUICAO_DO_PROJETO.md`.
2. Consultar `PROJECT_STATE.md`.
3. Consultar `docs/DECISOES.md`.
4. Consultar este arquivo.
5. Consultar `ROADMAP.md`.
6. Consultar o item correspondente no Linear.
7. Confirmar sincronização antes de alterar código.

## SKILL-002 — Alterar código

1. Trabalhar na branch vinculada à tarefa atual.
2. Limitar a mudança ao escopo autorizado.
3. Executar lint e build quando o ambiente permitir.
4. Registrar o resultado no `PROJECT_STATE.md`.
5. Atualizar o Linear.

## SKILL-003 — Processar imagens

1. Validar formato e tamanho.
2. Não armazenar a imagem por padrão.
3. Informar falhas de leitura claramente.
4. Separar texto bruto de dados estruturados.
5. Permitir revisão humana antes de persistir ou exportar.

## SKILL-004 — Publicar

1. Exigir autorização explícita.
2. Validar lint, build e critérios de aceitação.
3. Criar preview isolado.
4. Registrar URL e resultado no GitHub e no Linear.
