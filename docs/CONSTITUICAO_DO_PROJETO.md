# Constituição do Projeto

## 1. Identidade

Este repositório mantém o Laboratório 01 — Leitor Estruturado de Prints.

## 2. Objetivo

Construir uma aplicação que receba capturas de tela, extraia o conteúdo visível e organize o resultado em dados estruturados revisáveis.

## 3. Fontes oficiais

- GitHub: código, documentação e estado técnico permanente.
- Linear: execução, prioridade, critérios de aceitação e bloqueios.
- Vercel: previews e publicação, quando autorizados.
- Supabase: banco e armazenamento, quando autorizados.

## 4. Regras de execução

- Trabalhar em uma tarefa principal por vez.
- Relacionar alterações permanentes a uma tarefa do Linear.
- Não enviar ou armazenar imagens sem autorização explícita.
- Não publicar, excluir ou sobrescrever recursos externos sem autorização.
- Manter GitHub e Linear sincronizados antes de avançar.

## 5. Escopo do MVP

- Receber PNG e JPG.
- Validar o arquivo.
- Extrair texto por OCR.
- Organizar o resultado em estrutura JSON.
- Permitir revisão manual e exportação.

## 6. Fora do escopo inicial

- Garantia de leitura perfeita para qualquer imagem.
- Armazenamento automático dos prints.
- Treinamento de modelo próprio.
- Processamento irrestrito de documentos sensíveis.

## 7. Critério de conclusão

Uma etapa somente é concluída quando os critérios de aceitação forem atendidos, o resultado for aprovado e GitHub e Linear estiverem sincronizados.
