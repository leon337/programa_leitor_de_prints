# Manual Operacional do Projeto

## Fluxo diário

1. Confirmar o item atual no `PROJECT_STATE.md` e no Linear.
2. Verificar a branch vinculada ao item.
3. Executar somente a etapa autorizada.
4. Validar a alteração tecnicamente.
5. Atualizar documentação e Linear.
6. Solicitar aprovação antes de publicar ou avançar.
