# Decisões do Projeto

## DEC-001 — Stack inicial

Status: Aprovada

A fundação do MVP utiliza Next.js, React e TypeScript, com App Router.

## DEC-002 — Processamento inicial

Status: Aprovada

O primeiro OCR será integrado na aplicação após a validação da fundação. A estruturação começará com regras locais e poderá receber uma camada de IA em evolução futura.

## DEC-003 — Privacidade das imagens

Status: Aprovada

A imagem selecionada permanece local no navegador durante a fundação do MVP. Nenhum arquivo será enviado ou armazenado sem autorização explícita.

## DEC-004 — Infraestrutura externa

Status: Aprovada

Supabase e Vercel não serão configurados nesta etapa. A ativação de banco, armazenamento ou deploy exige autorização específica.

## DEC-005 — Fluxo operacional

Status: Aprovada

GitHub mantém o estado técnico permanente e Linear acompanha a execução. A tarefa atual é a LEA-100.
